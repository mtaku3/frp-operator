frp-operator ships as two Helm charts: `frp-operator-crd` (CRDs only, full Helm lifecycle) and `frp-operator` (controller deployment + RBAC). Install the CRD chart first, then the operator chart. Works on any conformant Kubernetes cluster — kind, minikube, EKS, GKE, AKS, on-prem.

## Prerequisites

- A running Kubernetes cluster (v1.28+)
- [`kubectl`](https://kubernetes.io/docs/tasks/tools/) v1.28+ configured for that cluster
- [Helm](https://helm.sh/docs/intro/install/) v3.14+

## Steps

<Steps>

1. **Install the CRD chart**

   The CRD chart registers the five CRDs (`ExitPool`, `ExitClaim`, `Tunnel`, `LocalDockerProviderClass`, `DigitalOceanProviderClass`). It must be installed before the operator chart.

   ```bash
   helm upgrade --install frp-operator-crd \
     oci://ghcr.io/mtaku3/charts/frp-operator-crd \
     --version 0.0.1 \
     --namespace frp-operator-system \
     --create-namespace \
     --wait
   ```

   Verify the CRDs exist:

   ```bash
   kubectl get crds | grep frp.operator.io
   ```

2. **Install the operator chart**

   ```bash
   helm upgrade --install frp-operator \
     oci://ghcr.io/mtaku3/charts/frp-operator \
     --version 0.0.1 \
     --namespace frp-operator-system \
     --wait
   ```

3. **Verify the operator pod is running**

   ```bash
   kubectl -n frp-operator-system get pods
   ```

   Expect one `frp-operator-*` pod in `Running` state:

   ```
   NAME                            READY   STATUS    RESTARTS   AGE
   frp-operator-7d9f8b6b5d-x4p2n   1/1     Running   0          30s
   ```

4. **Confirm leader election**

   ```bash
   kubectl -n frp-operator-system get lease
   ```

   A `frp-operator` lease should appear, indicating the controller acquired leadership.

</Steps>
