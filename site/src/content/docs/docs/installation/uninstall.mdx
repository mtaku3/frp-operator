frp-operator supports running on Kubernetes. Select the method that was used for installing frp-operator to go to the relevant uninstall documentation.

- [helm](/docs/installation/helm/#uninstalling)

If you need to preserve frp-operator custom resources (`Tunnel`s, `ExitPool`s, etc.) that are not version controlled or backed up by other means, export them before proceeding:

```bash
kubectl get tunnels,exitpools,exitclaims,localdockerproviderclasses,digitaloceanproviderclasses \
  --all-namespaces -o yaml > frp-operator-backup.yaml
```
