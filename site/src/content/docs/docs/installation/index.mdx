Learn about the various ways you can install frp-operator and how to choose between them.

## Default static install

> You don't require any tweaking of the frp-operator install parameters.

The default installation can be performed with Helm using the OCI registry:

```bash
helm install frp-operator-crd oci://ghcr.io/mtaku3/charts/frp-operator-crd \
  --namespace frp-operator \
  --create-namespace \
  --version 0.0.1

helm install frp-operator oci://ghcr.io/mtaku3/charts/frp-operator \
  --namespace frp-operator \
  --version 0.0.1
```

Read more about [installing frp-operator using Helm](/docs/installation/helm/).

## Getting started

> You quickly want to learn how to use frp-operator and what it can do.

**[helm](/docs/installation/helm/)**: You can use Helm to install frp-operator and this also allows you to customize the installation if necessary.

## Continuous deployment

> If you know how to configure your frp-operator setup and want to automate this, you can use the frp-operator Helm charts directly with tools like Flux. Or you can output YAML using `helm template` to generate customized frp-operator installation manifests, which can be piped into your preferred deployment tool.

Read more about [Continuous Deployment and GitOps](/docs/installation/continuous-deployment-and-gitops/).
