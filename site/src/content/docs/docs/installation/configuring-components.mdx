To configure the frp-operator components, you can use CLI flags or environment variables. CLI flags take precedence over environment variables.

## CLI flags

An overview of the available CLI flags for each component can be found on the following pages:

- frp-operator controller: [controller CLI flags](/docs/reference/flags/)

When using the Helm chart, the CLI flags can be specified in the `extraArgs` value:

```yaml
# values.yaml
extraArgs:
  - --log-level=debug
  - --leader-elect=true
  - --metrics-bind-address=:8080
```

<Aside type="note">
  frp-operator does not have a webhook component or a cainjector component. Only the controller binary accepts flags.
</Aside>

## Configuration file

frp-operator does not support a `--config` file flag. All configuration is passed directly to the operator binary via CLI flags or environment variables. There is no equivalent to cert-manager's `ControllerConfiguration` or `WebhookConfiguration` API.

## Feature gates

Feature gates can be used to enable or disable experimental features in frp-operator.

There are 2 levels of feature gates (more details in [Kubernetes definition of feature stages](https://kubernetes.io/docs/reference/command-line-tools-reference/feature-gates/#feature-stages)):

- **Alpha:** feature is not yet stable and might be removed or changed in the future. Alpha features are disabled by default and need to be explicitly enabled by the user (to test the feature).
- **Beta:** feature is almost stable but might still change in the future. Beta features are enabled by default and can be disabled by the user (if any issues are encountered).

The frp-operator controller has its own set of feature gates. They can be enabled or disabled using the `--feature-gates` flag. The available feature gates for the controller can be found in the [flags reference](/docs/reference/flags/).

Pass feature gates as a comma-separated list of `Name=bool` pairs:

```bash
--feature-gates=SomeFeature=true,AnotherFeature=false
```

When using the Helm chart, specify them in `extraArgs`:

```yaml
# values.yaml
extraArgs:
  - --feature-gates=SomeFeature=true,AnotherFeature=false
```
