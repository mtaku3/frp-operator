frp-operator is a Kubernetes operator that manages the full lifecycle of [frp](https://github.com/fatedier/frp)
server (`frps`) instances on cloud infrastructure. Instead of asking users to manually provision VMs and configure
`frps`, the operator watches `Tunnel` resources created by application teams, provisions the cloud exits needed to
serve them, and continuously reconciles the running state against the desired state declared in pool and provider
configuration.

The operator borrows its design vocabulary from [Karpenter](https://karpenter.sh): a cluster-scoped pool resource
defines the template and policy for a class of exits; the operator's scheduler allocates tunnels onto ready exits
or provisions new ones when existing capacity is insufficient; and a disruption controller continuously evaluates
running exits against a set of replacement conditions—emptiness, hash drift, expiration, and underutilization—
replacing any that no longer satisfy the pool's declared intent.
